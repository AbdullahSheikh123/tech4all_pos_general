## Tech4all POS General

Combined tech4all ERP and restaurant/POS functionality in one Frappe app.

The app contains both the **Tech4all POS General** and **Tech4all General**
modules. It includes restaurant ordering, KDS, stock takes and POS reporting,
along with document defaults, cheque management, cost-center controls,
announcements, price-list tools and general accounting customizations.
